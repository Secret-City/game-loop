# Brief 01 — Typewriter Code Console

**Difficulty:** ⚙⚙⚙ · **Bench time:** ~3 days · **Stage:** timecore (`RCB008` recalibration) + microfilm

## Mission

Retrofit a vintage typewriter into the room's physical keyboard. When the dashboard
enters phase **`RCB008`** it displays the recalibration code **`i u k a c`** (letter-key
art from `/public/keys/`). Players must *type the code on the typewriter* to recalibrate
the Harmonics Core. The same typewriter doubles as the input device for the microfilm
reader codes (`iukac`, `xhjym` in any order — see `src/Microfilm.tsx`).

A hidden **thermal printer** in the typewriter body prints "telegrams from a previous
loop" — hint messages generated by the LOOP AI (Brief 09).

## Game context (code references)

- `SecurityDashboard.jsx` phase `RCB008` → overlay "recalibrate the harmonics core with
  this code" + key images. Success/failure sounds already exist:
  `recalibration_required/pending/successful/loss.mp3`.
- `Microfilm.tsx` accepts physical `keydown` events, so a USB-HID variant can drive it
  directly; the MQTT variant lets Node-RED validate instead.
- `/public/keys/` has glyphs for every letter **except d and p** — codes must avoid those.

## Step-by-step build

1. **Teardown & survey (½ day).** Remove the typewriter's bottom plate. Watch how the
   keybars swing when a key is pressed. Decide sensing strategy:
   - *Microswitch:* mount a lever microswitch under each keybar you care about.
     You do NOT need all 26 — the game only ever validates letters; sense the ~12
     letters used across codes (`i u k a c x h j y m` + 2 spares) plus a "any other key"
     bus switch, and you cut the build time in half.
   - *Hall:* epoxy a 3×2 mm magnet to each keybar, hall sensor on a 3D-printed rail below.
     Cleaner action, more fiddly alignment. Prototype ONE key both ways, then commit.
2. **Sensor rail (1 day).** 3D-print or laser-cut an acrylic rail that bolts to the frame
   and holds all sensors at consistent depth. Wire each sensor to an ESP32 GPIO through
   the rail to a perfboard header (use both GPIO banks; you have plenty of pins — a
   matrix is not worth the complexity here). Debounce 25 ms in firmware.
3. **Feedback hardware (½ day).** Mount the solenoid so it taps the typewriter's real
   bell on command. Fit the amber READY lamp through an existing badge hole. Hide the
   thermal printer inside the rear body panel with the paper slot exiting where the
   paper platen would feed — a telegram physically rises out of the typewriter.
4. **Firmware (½ day).** Base platform (README §3) plus:
   - publish `loop/typewriter/event` → `{"event":"key","char":"i"}` per press
   - subscribe `loop/typewriter/cmd`:
     `{"cmd":"ding"}` → solenoid 80 ms; `{"cmd":"ready","on":true}` → lamp;
     `{"cmd":"print","text":"..."}` → thermal printer (word-wrap 32 cols, feed 4 lines);
     `{"cmd":"reset"}` → clear buffer, lamp off.
   - *USB-HID mode (compile flag):* the S3 also enumerates as a USB keyboard and types
     the character — plug it into the microfilm kiosk and `Microfilm.tsx` works with
     zero server changes. Ship both; default to MQTT.
5. **Node-RED flow (½ day).** Accumulate keys into a buffer; on match against the
   active stage's code: publish `{"cmd":"ding"}`, play `recalibration_successful.mp3`
   via `/ws/wall` audio message, advance the dashboard phase. On mismatch after N chars:
   `incorrect_sequence.mp3` + `{"cmd":"reset"}`.
6. **Dress it (½ day).** Facility asset tag ("HARMONICS TERMINAL #0271 — INPUT UNIT"),
   worn instruction card in the paper tray, cable exits through desk grommet.

## Test checklist

- [ ] Every sensed key registers exactly once per press at fast typing speed
- [ ] `iukac` during `RCB008` → ding + success sound + dashboard advances
- [ ] Wrong code → fail sound, buffer clears, lamp blinks
- [ ] `{"cmd":"print"}` telegram prints and is legible
- [ ] Survives 15 minutes of a frustrated player mashing keys
- [ ] OTA reflash works with the bottom plate screwed shut

## Stretch goals

- Per-key press also fires a `pop.mp3` on the wall for a satisfying room-wide echo.
- Ribbon-select lever as a hidden input (hall sensor) for a bonus puzzle.
